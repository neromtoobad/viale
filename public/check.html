Check before you pay, from your own agent

Viale runs an MCP server with one job: check_agent returns trade only if every check passes, else walk_away with the reasons. Add it to Claude Code:

claude mcp add --transport http viale https://viale.nerom.site/mcp

Or call it over HTTP:

curl https://viale.nerom.site/api/check/1527

Read-only, no keys or sign-in. Up to 30 checks a minute per address; each result is at most five minutes old.
