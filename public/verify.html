How the check works
Sealsha256(JSON(receipt) ‖ nonce) must equal the 32 bytes after VIALE/R1 in the register-data transaction
SignatureConcordium account message signature, checked against the signer’s current keys read from a node
WhereViale’s server calls a public testnet node; the code is history.ts ↗

Or recompute the hash yourself, with nothing from Viale:

node -e '
const r = require("./log.json");
const h = require("crypto").createHash("sha256")
  .update(JSON.stringify(r.receipt))
  .update(Buffer.from(r.anchor.nonce, "hex"))
  .digest("hex");
console.log(h, r.anchor.hash)'

Then open the transaction on CCDExplorer ↗ and compare its registered data.
