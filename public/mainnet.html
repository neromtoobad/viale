The steps

What’s left, in order

  1. Point the checks at mainnet

    Switch the registry to <10082,0> and read owner identities from a mainnet node. The checks themselves don’t change.

    Code ready
  2. Shops open and run their own agents

    An owner connects a wallet, registers the agent and signs a price list. Next, they host the menu and quote endpoints on their own server with their own key; Viale stays the directory and the errand agent.

    Started: /open
  3. A regulated euro

    Pay in a mainnet euro PLT. A shop with a business identity gets onto the allow-list and takes payment at its own account, so no separate till.

    Needs an issuer
  4. Limits on chain

    The human already signs budget, cap, shops and expiry. Next, a contract holds the agent’s funds and enforces those signed numbers, so not even Viale’s server can overspend.

    Design
  5. 18+ goods

    The Verify & Access flow is written. The ID app is a mainnet app, so it should work there as is.

    Code ready
  6. Who pays

    Shops pay a small fee per errand; agent platforms pay for checks beyond a free tier. Viale keeps paying transaction fees through sponsored transactions.
